# 주사위 영웅전 UI 개편 기획 (2026-11-17)

전체 화면 62장(자동 사진)을 다시 보고 정리한 기획이다. 기획·검토는 Fable, GPT 에셋 주문과 적용은 Opus가 맡는다(사용자 결정).
기준 시안은 ChatGPT 대화 '게임 UI 재디자인 요청'의 시안 B(지금 기능만으로 그린 것)와 타이틀 시안이다.
시안에 있어도 게임에 없는 기능(장비·각성·난이도 탭·프리셋 5칸 등)은 넣지 않는다.

## 1. 지금 상태 진단

잘 된 곳: 타이틀·로그인(금빛 로고), 로비(밝은 타일), 금테 창(grand 창), 대전 판, VS·BATTLE 연출.

고칠 곳(중요한 순서):

1. **버튼이 세 가지 모양으로 섞여 있다.** 금테 알약(소환·출전), 테 없는 광택(켜짐·작게·크게·진행 중·받기), 납작한 단색(파티 화면 탭·뒤로·칸에 저장). 한 화면에 같이 보여 어수선하다.
2. **큰 판 안의 작은 판 색이 제각각이다.** 상점은 보라·주황 머리, 미션은 초록, 모험은 숲색, 패스는 황토색. 틀은 남색으로 맞췄는데 안쪽이 안 맞는다. 받아 둔 목록 줄(list_row)·탭(tab_on/off)을 아직 안 쓴다.
3. **파티 화면이 가장 동떨어져 있다.** 빨강·보라 납작 카드, 단색 탭, 작은 글자. 영웅 화면의 금테 카드와 전혀 다르다.
4. **작은 창의 글자가 너무 작다.** AI 난이도, 우편함, 수집 앨범, 스킬 설명, 환영 창은 창도 작고 글자가 10~12px로 보인다.
5. **왼쪽 세로 판 아래가 비어 있다.** 항목이 2~4개뿐인 화면은 판의 절반 이상이 빈 남색이다.
6. **홈 버튼이 무엇인지 알아보기 어렵다.** 장식이 많은 작은 아이콘이라 집 모양이 안 보인다.
7. **대전 결과 화면이 글자 목록이다.** 오른쪽에 줄글이 9줄 나열돼 있어 읽기 힘들고 보상이 눈에 안 띈다.
8. **'상대를 찾는 중' 화면이 파란 바탕에 글자뿐이다.**
9. **룰렛 바퀴가 도형으로 그린 그림이라 다른 금테 부품과 안 어울린다.**
10. **대전 화면**: 오른쪽 위 '나가기'가 아직 화면 밖으로 잘린다. 정보판·스킬 카드 글자가 작다. 처음 안내 상자가 판 한가운데를 가린다.
11. **로비와 메뉴의 재화 칸 모양이 다르다.**
12. **알림 띠(토스트)가 화면 위쪽 내용을 가린다.**
13. **연출이 없다.** 메뉴 화면이 한 번에 나타나고, 항목을 바꿔도 움직임이 없다.

## 2. 공통 규칙(모든 화면)

- **색**: 메뉴 화면은 남색 판 + 금테 + 보라 보석. 로비만 밝은 하늘·타일(사용자가 좋아한 것, 유지).
- **버튼은 금테 알약 하나로 통일**하고 색으로 뜻을 나눈다.
  - 주황/금: 가장 중요한 한 가지(받기·출전·소환 10회·보상 모두 받기)
  - 초록: 가기·확인·켜짐·시작
  - 파랑: 보조(닫기·뒤로·바로가기·작게)
  - 빨강: 나가기·삭제
  - 회색: 못 누름(진행 중·잠김·준비 중·꺼짐)
  - 보라: 특별(프리미엄·한마디)
  - 크기는 세 가지만: 큰(높이 72), 보통(56), 작은(44). 글자 26/22/18.
- **큰 판 안쪽**: 묶음마다 `구역 머리띠`(왼쪽 아이콘 + 금색 제목, 오른쪽 작은 설명) 아래에 `목록 줄`을 쌓는다. 목록 줄은 남색 + 얇은 금테, 왼쪽 아이콘(48) · 제목(24)과 설명(18) · 오른쪽에 수치와 버튼. 화면마다 다른 판 색은 쓰지 않는다.
- **탭**: 고른 것은 노란 알약(tab_on), 나머지는 파란 알약(tab_off). 분류 탭만 분류 색을 쓴다.
- **글자 크기 바닥**: 본문 18, 보조 16 아래로 내리지 않는다(1280×720 기준).
- **창(팝업)**: 너비는 화면의 45% 이상, 제목 리본 28, 본문 20 이상. 버튼은 아래 한 줄.
- **왼쪽 세로 판**: 항목 아래 빈 곳에 그 화면의 요약 카드를 넣는다(아래 화면별 안 참고). 요약 카드는 작은 금테 판에 아이콘 + 두 줄 글.
- **홈 버튼**: 동그란 금테 파란 버튼에 흰 집 그림. 그 옆 제목 명판은 그대로.
- **재화 칸**: 로비도 메뉴와 같은 캡슐(currency + 초록 더하기)로 맞춘다.
- **알림 띠**: 화면 맨 위 가운데 대신 제목 명판과 재화 칸 사이(위 줄 높이 안)에 뜨게 해서 내용을 안 가리게 한다.

## 3. 연출 규칙

- **화면 등장**(0.25초): 위 줄은 위에서 내려오고, 왼쪽 판은 왼쪽에서 밀려 들어오고, 큰 판은 살짝 커지며 나타난다. `app.instant`(자동 사진)·저사양 모드에서는 건너뛴다.
- **항목 전환**: 왼쪽 항목을 누르면 큰 판 내용이 0.15초 페이드로 바뀐다.
- **버튼**: 누르면 96%로 줄었다가 돌아온다. 가장 중요한 버튼만 빛이 훑고 지나간다(이미 있는 `Kit.shimmer`).
- **받기**: 보상을 받으면 버튼 자리에서 금화·보석 알갱이가 위 줄 재화 칸으로 날아가고 숫자가 올라간다(이미 있는 `fx.burst`의 coin 사용).
- **창**: 금테 창은 0.2초 동안 90%→100%로 커지며 뜬다.
- **배경**: 메뉴 배경 그림을 덮는 어두운 막을 0.38→0.25로 줄이고, 위 줄 뒤로 배경이 보이게 한다(시안 B처럼 하늘·성이 위에 보이도록).

## 4. 화면별 안

### 영웅
- 왼쪽: 영웅 목록 · 영웅 앨범 · 파티 편성. 아래 요약 카드: "모은 영웅 12 / 48", "출전 파티" 작은 초상화 3개.
- 큰 판: 위 한 줄에 `영웅 도감 12/48`(월계수 장식) + 일괄 강화(초록) + 보유만 보기(파랑, 켜지면 체크 표시).
- 카드: 금테 틀, 이름 띠 글자 18, 별·레벨 16(지금은 너무 작음). 없는 영웅은 어둡게 + 자물쇠.
- 영웅 상세 창: 그대로. 능력 막대 끝 숫자 옆에 주사위 아이콘.

### 파티 편성 · 파티 확인(가장 많이 바꿈)
- 큰 판을 좌우로 나눈다. 왼쪽 42%: 제목(금색 28) → ATTACK·DEFENSE·SUPPORT 자리 카드 3장(금테 세로 카드, 위 띠 색 빨강·보라·초록, 초상화, ★이름, 그 자리 능력 한 줄) → `소환 포인트 5/5`와 시너지를 캡슐 두 개로 → 저장 칸 줄(칸에 저장 + 1·2·3번) → 설명 판 → 아래 버튼 줄(뒤로 파랑 · 자동 추천 파랑 · 대전 시작/저장 초록 큰 버튼).
- 오른쪽 58%: 분류 탭(영웅 화면과 같은 알약) → 영웅 카드 4열. 카드는 영웅 화면과 같은 금테 틀을 쓰고, 이름 띠 아래에 "이동1 공5 방2 지1"을 주사위 아이콘 없이 16으로. 분류 색은 카드 왼쪽 위 작은 동그란 표식으로만.
- 고른 영웅은 금테가 밝아지고 체크 표시.

### 상점
- 왼쪽: 영웅 소환 · 성장 · 주사위 · 보석. 아래 요약 카드: "오늘 무료 소환 1회", "확정까지 40회".
- 소환: 큰 그림 띠는 유지. 확률·보장 글은 캡슐 두 개로. 버튼 3개(무료 초록 · 1회 파랑 · 10회 금색)에 보석 아이콘.
- 성장(유물·골드 교환)·주사위·보석: 구역 머리띠 + 목록 줄. 가격 버튼에 골드·보석 아이콘. 보라·주황 판 색은 없앤다.
- 주사위 상점: 주사위 칸을 금테 작은 카드(주사위 그림 + 이름 + 가격 알약)로.

### 미션
- 왼쪽: 오늘 미션 · 업적. 아래 요약 카드: "오늘 완료 3 / 6".
- 큰 판: 보상 모두 받기(금색 큰 버튼, 양끝 선물 상자) → 길잡이 과제(목록 줄, 초록 판 없앰) → 출석 보상(7칸 금테 칸, 오늘 칸은 금색으로 빛남, 받은 칸은 도장) → 일일 미션 목록 줄(왼쪽 아이콘, 진행 막대, 오른쪽 보상 캡슐 + 받기/바로가기/진행 중).
- 업적: 목록 줄 왼쪽에 트로피, 진행 막대, 보상 캡슐, 버튼. 맨 위에 달성도 막대.

### 설정
- 왼쪽: 게임 설정 · 게임 방법 · 타이틀로. 아래 요약 카드: 버전, 닉네임.
- 큰 판: 구역 머리띠 3개(소리 / 게임 / 계정)로 묶는다. 줄마다 왼쪽 아이콘(전용 아이콘 새로 주문), 오른쪽 켜짐(초록)·꺼짐(회색) 알약. 소리 크기는 작게·크게 사이에 5칸 눈금 막대.

### 모험
- 왼쪽 판을 만든다: 장 목록(1장 초원의 길 … 9장). 깬 장은 별 개수, 잠긴 장은 자물쇠. 고른 장만 큰 판에 보인다(지금은 세로로 길게 스크롤).
- 큰 판: 장 그림 띠 → 장 이름·맵 모양·수호자 → 스테이지 버튼 3개(깬 것 초록 + 별, 다음 것 금색, 잠긴 것 회색 + 자물쇠).
- 스테이지 창: 그대로. 버튼만 통일(출전 금색 · 소탕 초록 · 닫기 파랑).

### 시즌 패스
- 위: 시즌 이름 + 패스 레벨 막대 + 보상 모두 받기.
- 아래: 레벨 줄. 무료 보상은 알약 버튼, 프리미엄은 황토색 판 대신 회색 금테 줄 + 자물쇠 + "준비 중".

### 게임 방법
- 그대로(왼쪽 묶음 5개). 설명 판을 목록 줄 모양으로, 제목 앞에 아이콘.

### 로비
- 배치는 유지. 재화 칸만 메뉴와 같은 캡슐로. 위 시스템 버튼 줄 글자(공지·우편 등)를 14로 키운다.

### 로비 창
- 환영·AI 난이도·우편함·수집 앨범: 창 너비 600 이상, 글자 20 이상으로 키운다.
- AI 난이도: 쉬움·보통·어려움을 가로 카드 3장(이름, 상대 레벨, 보상 배수)으로.
- 룰렛: 바퀴를 그림(금테 바퀴 + 위 화살표)으로 바꾼다. 칸 색과 글자는 코드가 그 위에 그린다.
- 프로필·리그·오늘 할 일·홀짝: 버튼만 통일.

### 대기 화면
- '상대를 찾는 중': 대전 준비 중과 같은 배경 그림 + 가운데 돌아가는 금테 주사위 문양 + 아래 도움말 한 줄.

### 대전
- 오른쪽 위 버튼 줄이 화면 안에 다 들어오게 한다(자동·빠르기·나가기).
- 정보판 이름 20, 설명 16. 스킬 카드 이름 17, 게이지 숫자 16.
- 처음 안내 상자는 판 가운데가 아니라 아래 스킬 카드 줄 바로 위에, 높이를 줄여서.
- 스킬 설명 창: 너비 640, 글자 20.

### 대전 결과
- 왼쪽 40%: VICTORY/DEFEAT 로고 → MVP 금테 카드(초상화, 이름, 자리).
- 오른쪽 60%: `결과 줄` 5개(아이콘 + 이름 + 값): 진행 턴 · 남은 거리 · 전투 · 깬 관문 · 트로피. 그 아래 `얻은 보상` 금테 칸들(골드·경험치·트로피·패스, 아이콘 크게 + 숫자).
- 아래: 로비로(파랑) · 다시 하기(금색). 레벨 업·미션 완료 같은 알림은 결과 줄 아래 작은 띠로.

## 5. GPT에 주문할 개별 에셋

모두 자홍(#FF00FF) 단색 바탕, 부품끼리 넓게 띄움, 글자·숫자 없음, 그림자·바닥 빛 없음, 정면. 남색 판 + 금테 + 보라 보석 스타일. 16:9 한 장에 8~12개.

**시트 A(버튼·줄)**: 알약 버튼 몸통 6색(금/주황, 초록, 파랑, 빨강, 회색, 보라, 모두 같은 모양·금테, 비율 3.2:1) · 동그란 홈 버튼(파란 구슬 금테 + 흰 집) · 구역 머리띠(왼쪽 동그란 아이콘 자리, 비율 9:1) · 보상 캡슐(작은 어두운 알약, 2.6:1) · 요약 카드 판(1.6:1).

**시트 B(카드·칸)**: 파티 자리 카드 틀 3색(세로 3:4, 위 띠 빨강·보라·초록, 안쪽 그림 자리 자홍) · 출석 칸 3종(보통·오늘[금빛]·받음) · 도장(빨간 '완료' 느낌의 체크 도장, 글자 없이 체크) · 주사위 상품 카드 틀(1:1.25) · 결과 줄(8:1, 왼쪽 아이콘 자리) · 보상 칸(1:1 금테) · 잠긴 줄(회색 금테 8:1).

**시트 C(아이콘, 4×4)**: 스피커 · 음표 · 마이크 · 확성기 · 번개(빠르기) · 모니터(전체 화면) · 눈금 속도계(저사양) · 쿠폰 · 연필(이름) · 막대 그래프(전적) · 자물쇠 · 체크 · 선물 상자 · 집 · 깃발 든 성(장) · 돌아가는 화살표(다시 하기).
