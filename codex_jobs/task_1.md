# task_1: 파티·카드 편성 화면 개선 (등급 거름, 영웅·카드 정보 창)

먼저 `AGENTS.md`와 `CLAUDE.md`를 읽고 규칙을 따른다.

## 할 일
사용자 요청 세 가지.
1. 파티 편성에서 분류 탭(전체·영웅·위인·신화·근현대)을 누르면, 그 아래에 등급 탭(전체·★★★·★★·★)이 나와서 등급으로도 거를 수 있게 한다.
2. 파티 편성에서 영웅 카드를 누르면 바로 넣지 말고, 영웅 정보 창을 띄운 뒤 "이 무장으로 적용할까요?"라고 묻는다. '적용'을 누를 때만 지금 고른 자리에 넣는다.
3. 카드 편성에서 오른쪽 '보유 카드'의 카드를 누르면 바로 넣지 말고, 카드 정보 창을 띄운 뒤 "이 카드로 적용할까요?"라고 묻는다. '적용'을 누를 때만 덱에 넣는다.

## 고칠 곳
### 1. 등급 탭 — `scripts/ui/party_select.gd`
- 지금 분류 탭은 `_build()` 안 207~217줄쯤(`for category in ["", "영웅", "위인", "신화", "근현대"]`), 거르기는 `_filter`, 누르면 `_on_filter_pressed`.
- `_grade_filter := 0`(0=전체, 3·2·1)을 더하고, 분류 탭 줄 바로 아래에 등급 탭 줄(전체·★★★·★★·★)을 만든다. 모양은 분류 탭과 같은 알약 버튼(`_plain_button` + 같은 크기, 고른 탭은 분류 탭처럼 표시).
- 등급 탭 줄은 처음에도 보여 두되(분류 탭을 하나 누른 뒤에만 보이게 하지 말 것 — 사용자가 "각 버튼을 누르면 별등급이 나와서"라고 했으므로, 분류를 고르면 그 분류 안에서 등급으로 다시 거를 수 있다는 뜻), 분류를 바꾸면 등급은 '전체'로 돌아간다.
- 영웅 목록을 거르는 곳에서 `_filter`와 함께 `_grade_filter`도 본다(`int(character["grade"]) == _grade_filter`).
- 화면 높이가 모자라면 영웅 목록 칸 높이를 줄여 맞춘다. 버튼이 큰 판(금테) 밖으로 나가거나 겹치면 안 된다.
- 길잡이(튜토리얼) party 단계는 버튼 메타 `guide`로 저장 버튼(`party_save`)을 가리킨다. 이건 그대로 둔다.

### 2. 영웅 정보 창 — `scripts/ui/party_select.gd`
- `_on_character_pressed(id)`는 지금 곧바로 넣는다. 이걸 "창 띄우기"로 바꾸고, 지금 넣는 코드는 `_apply_character(id)`로 옮긴다.
- 창은 `scripts/ui/dialog.gd`(Dialog.new(); add_child; open(제목, 내용, 버튼들)) 를 쓴다. 제목은 영웅 이름.
- 내용: 왼쪽에 초상화(`scripts/ui/portrait.gd` 또는 화면에서 이미 쓰는 초상화 방식), 오른쪽에 등급(★), 분류, 능력치(이동·공격·방어·지력 — 레벨에 맞춘 값은 기존 `_level_of`·`_from_table`을 써서 지금 목록 카드에 보이는 값과 같게), 어빌리티 이름·설명(`abilities`), 어빌리티 아이콘(`GameData.ability_icon_rect` 있으면). 맨 아래 한 줄: "이 무장으로 적용할까요? (자리: 공격/방어/지원)" — 자리 이름은 지금 고른 `_active_slot`.
- 버튼: [적용](초록, `_apply_character(id)`), [취소](연파랑). 이미 지금 자리에 있는 영웅이면 버튼 글을 '이미 편성됨'으로 하거나 적용 버튼을 끈다.
- 사용자가 못 가진 영웅은 지금처럼 동작(목록에 원래 나오지 않으면 신경 쓰지 않음).
- 기존 `_show_info(id)`(아래 정보 글줄)는 창을 띄울 때도 그대로 불러도 된다.

### 3. 카드 정보 창 — `scripts/ui/card_panels.gd`
- 카드 편성(`build_deck`)의 오른쪽 보유 카드를 누르면 `_on_card(id)`가 불린다. 이미 덱에 있는 카드(왼쪽 덱 줄을 누른 경우 포함)는 지금처럼 바로 뺀다. 덱에 없는 보유 카드일 때만 창을 띄운다.
  - 왼쪽 덱 줄과 오른쪽 보유 카드가 같은 `_on_card`를 쓰면, 오른쪽에서 덱에 이미 든 카드를 누른 경우에도 창 없이 바로 빼면 된다.
- 창 내용: 카드 그림(`card_tile(cards, id, true, false, 큰 높이, false)` 재사용 가능), 등급 ★, 이름, 효과 설명(`text`). 맨 아래 "이 카드로 적용할까요?".
- 버튼: [적용](초록) → 지금 `_on_card`의 넣는 부분(`Profile.toggle_deck`, 문제 있으면 toast, 저장, `_back`). [취소].
- 등급 자리가 꽉 차서 못 넣는 경우는 지금처럼 `toggle_deck`이 돌려주는 글을 toast로 보여 준다(창을 닫은 뒤).
