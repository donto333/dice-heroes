# 그림 주문서: 새 아이템 카드 25장 (job_cards2)

게임 '주사위 영웅전'의 아이템 카드 그림이다. 카드 칸을 그림이 가득 채우고, 아래쪽에 게임이 카드 이름을 얹는다.

## 먼저 할 일

1. `git pull` 로 최신 저장소를 받는다.
2. 이미 있는 카드 그림 `assets/art/cards/*.jpg` 를 몇 장 열어 본다(특히 `banner.jpg`, `fortress.jpg`, `swift_horse.jpg`, `whirlwind.jpg`, `herb.jpg`, `keen_blade.jpg`, `silence_bell.jpg`, `war_god.jpg`). **새 그림은 이 그림들과 같은 세트로 보이게** 그린다.

## 공통 조건

- 크기: 정사각형 1024 × 1024, 카드 한 장당 그림 한 장.
- 그림체: 위 기존 카드와 같은 화려한 판타지 채색 일러스트. 노을빛 구름 하늘, 금빛 빛줄기, 붉은 천·금 장식, 멀리 성벽·누각이 보이는 동서양이 섞인 고풍 배경.
- 구도: 카드의 주제(물건·동물·장면) 하나를 가운데에 크게. 그림 아래쪽 1/5은 이름 띠가 덮으므로 중요한 것은 그 위에 둔다.
- 바탕은 그림으로 꽉 채운다(자홍·단색 바탕 아님). 테두리·액자 없음.
- **글자·숫자·기호를 그리지 않는다.** 깃발·책·두루마리의 무늬는 알아볼 수 없는 장식으로.
- 사람이 나오면 얼굴이 작게, 실존 인물·실존 게임·영화·만화의 캐릭터 디자인을 흉내 내지 않는다.
- 등급에 따라 빛의 화려함을 다르게: ★ 일반은 차분하게, ★★ 희귀는 푸른빛·보랏빛 효과를 조금, ★★★ 전설은 금빛 광채가 가장 화려하게.

## 저장

1. 위 표의 파일 이름 그대로 25장을 저장소의 `codex_out/cards2/cards/` 에 저장한다(가운데 `cards` 폴더 이름을 꼭 지킨다).
2. 새 브랜치 `codex/card-art-2` 를 만들어 `codex_out/cards2/` 폴더만 커밋해 GitHub에 올린다(`git push -u origin codex/card-art-2`). main에는 올리지 않는다.
3. 다 그리면 25장을 한 번씩 열어 보고, 글자·숫자가 들어갔거나, 기존 카드 그림과 너무 다른 그림체이거나, 주제가 아래쪽 1/5에 가려지는 것은 다시 그린다.
