# 그림 주문서: 카드 편성 화면 부품 (job_deck)

## 먼저 할 일

1. `git pull` 로 최신 저장소를 받는다.
2. 아래 참고 그림을 열어 재질·색감을 맞춘다.

게임: 주사위 영웅전 (가로 1280×720 모바일 보드게임 RPG)
참고 그림(이 재질·색감과 똑같이): `assets/ui_menu/day_cell.png`, `assets/ui_menu/content_panel.png`, `assets/ui_menu/list_row.png`, `assets/ui_menu/hero_card.png`
스타일: 진한 남색 판에 두툼한 금테, 모서리 보라 보석 장식, 위쪽 은은한 광택. 밝고 화려한 캐주얼 판타지.

## 공통 규칙
- **글자를 넣지 않는다.** (한글·영어·숫자 모두)
- 부품마다 **단색 자홍 바탕 #FF00FF** 위에 하나씩 그린다. 그림 안에는 자홍색을 쓰지 않는다. 바깥 그림자는 그리지 않는다.
- 한 파일에 부품 하나. 부품이 그림을 꽉 채우되 가장자리에 자홍 여백을 조금 남긴다.

## 저장

1. 저장소의 `codex_out/deck/` 에 위 파일 이름 그대로 7장(PNG)을 저장한다.
2. 새 브랜치 `codex/deck-art` 를 만들어 그 폴더만 커밋해 GitHub에 올린다(`git push -u origin codex/deck-art`). main에는 올리지 않는다.
